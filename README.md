# PLP Python Week 4 Assignment

## File Descriptions
- **welcome.py**: A simple script welcoming users to the Python Week 4 assignment.
- **toolbox.py**: A module containing reusable functions for doubling numbers, checking pass scores, and generating personalized greetings.

## Reflection
The `greet` function was the most interesting to write because it required setting a default parameter value (`greeting="Hello"`) to handle optional inputs cleanly without extra logic.
